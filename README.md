# Carlos JR

Sitio web hecho para un supuesto restaurante de comida rapida.

## Estructura

- `public/`: archivos accesibles del sitio web.
- `public/index.html`: página principal.
- `public/pages/`: páginas adicionales del sitio.
- `public/assets/images/`: imágenes del sitio.
- `public/css/`: hojas de estilo.
- `public/fonts/`: fuentes locales.
- `public/vendor/`: dependencias JavaScript servidas directamente por el sitio.
- `public/js/`: scripts del sitio.
- `public/js/compartido/`: módulos reutilizables.
- `public/js/inicio/main.js`: punto de entrada de la página principal.
- `public/js/menu/`: `main.js` coordina eventos, `ui.js` actualiza la interfaz y `productos.js` carga los datos del menú.
- `public/js/registro/`: módulos del registro: eventos, validaciones e interfaz.
- `api/data/`: datos compartidos por la aplicación.
